Referência rápida

  

    Todos os POST aceitam JSON no corpo e retornam { ok, ... }.

    GET /api/state — snapshot completo (semáforos, vias, câmeras, subestações, métricas).

    GET /api/health — uptime, tick, clientes SSE e memória do processo.

    GET /api/history?n=600 — séries temporais (congestão, energia, ameaça).

    GET /api/events?n=200 — log de eventos (mais completo que o snapshot).

    SSE /api/stream — estado ao vivo a cada tick (1 Hz) + heartbeat 15 s.


    Exemplo: curl -X POST http://localhost:3000/api/light -H "Content-Type: application/json" -d '{"id":"L-0-0","mode":"blink"}'
